# 根拠ポリシー

このアプリの課題は、研究・公式指導体系・コーチ実践資料を課題設計の参考にした監修前ドラフトです。参考資料は課題の設計観点を支えますが、個別課題の効果、全員への適合、安全性、競技成績の向上を証明するものではありません。

資料を登録するときは、一次資料または発行元が明確な資料を優先し、タイトル、著者・組織、年、URL、確認日、`supports`（支持する範囲）、`doesNotProve`（支持しないこと）を記録します。課題側では登録済みの `evidenceIds` のみ参照します。

研究結果から直接導けない「必ず上達する」「最適である」などの断定は表示しません。外部URLが開けない場合も、課題本体は動作し、根拠の限界を画面に示します。実施の安全判断と個別化は、現場の有資格者・指導者が行います。
